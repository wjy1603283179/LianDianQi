## 真实 Windows 输入与进程测试

对打包后的 LianDianQi.exe 运行 tests/native_smoke.py：

- 无实例时控制命令不会启动后台程序。
- 重复启动只显示同一实例。
- 全局停止快捷键释放实际被模拟按下的 F24。
- 本地控制命令切换任务、停止任务，释放保持中的按键。
- 标题栏关闭对应的 WM_CLOSE 释放按键、退出进程并注销快捷键。
- 五次真实键盘输入产生五组按下/抬起。
- 四次真实鼠标点击落在测试窗口指定物理坐标 (120, 120)。
- FloatingBall 使用的 --quit 正常释放长按并退出，所有被测试进程结束。
- PATH 只保留 Windows System32、清除 Qt 开发环境变量后，便携包窗口正常运行。

关闭耗时本次约 56 ms。空闲窗口工作集约 42.8 MiB，私有内存约 15.2 MiB；
无限长按工作集约 43.6 MiB，私有内存约 15.7 MiB。
2 秒短样本中 CPU 为单核心的约 0.8% / 1.6%，会受到窗口绘制与 Windows 计时粒度影响，
不能作为所有机器上的固定占用保证。执行器空闲与无限长按状态无活动定时器。
