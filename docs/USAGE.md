# 点序 · 使用说明

解压完整文件夹，双击 `LianDianQi.exe`。不需要安装 Qt、Python 或启动其他服务。
请保留同目录的 DLL、platforms 文件夹及 qt.conf。

## 快速任务

1. 选择动作：连点、长按、按下、抬起或按一次。
2. 点击“采集”，实际按下需要的鼠标按钮或键盘按键。
3. 设置间隔、次数或持续时间。次数为 0 表示持续连点；长按时间为 0 表示保持到停止。
4. 按“开始任务”或 F6，利用默认 2 秒启动延迟切到目标窗口。
5. F6 再次按下会停止，F8 可立即停止。长按和“按下”停止后会释放。

鼠标默认在当前位置执行；勾选“固定鼠标位置”后可拾取目标位置。
时间字段使用独立的 ms / s / min 下拉框，切换单位会换算当前数值。
拾取时透明覆盖层会接收点击，不会误点其他窗口；选完后回到原窗口，Esc 可取消。
坐标是屏幕物理像素，支持多屏和负坐标；覆盖层包含每块屏幕的完整范围和任务栏。
不同分辨率形成的屏幕外空白区域不能作为目标坐标。拾取过程中调整显示配置会取消本次拾取。

## 脚本流程

添加步骤、选择卡片编辑属性、拖动卡片调整顺序。也可复制、删除和导入/保存 JSON。
支持连点、长按、按下、抬起、按一次、等待、移动鼠标、循环开始和循环结束。
也支持“如果找到图像”“否则”“结束条件”和“点击匹配中心”。添加图像条件时自动放入中心点击和结束条件，可继续插入其他动作；分支和循环以缩进显示。
循环开始/结束之间必须至少有一个步骤；可嵌套 16 层。
脚本页底部“脚本循环”控制整条流程的重复次数，0 表示无限循环；其他页面不显示。
所有步骤正常结束时会释放未配对的按下；脚本中的无限长按会等待手动停止。

点击“录制输入”或 F7，把真实键盘和鼠标按钮事件追加到流程末尾。再次按 F7 结束。
录制保留按下/抬起、点击位置和间隔；不录制鼠标移动轨迹、滚轮或程序模拟输入。
录制结束时会为仍未抬起的键添加抬起步骤；在外部按下、拖回点序窗口后松开的鼠标也会正确配对。
录制不发送任何模拟输入。

## 图像匹配

在脚本中添加“如果找到图像”，用“截图”拖动框选模板，或导入 PNG / BMP。模板直接保存在脚本里，移动脚本不需要额外复制图片。
模板尺寸为 8～1024 像素，每张 PNG 最多 2 MB，整个脚本最多 4 MB。
“限定识别范围”支持拖动框选屏幕区域；坐标使用物理像素，可含副屏的负坐标。范围越小，截图和搜索通常越快。
不限定时依次搜索全部显示器，单个模板不跨两块显示器拼接匹配。

相似度默认 88%，可设置 60～100%，滚轮不会改变此数值。保留与目标相同的背景，截图尽量贴近目标并留少量边缘；不要只截纯色背景。
同一范围有多个满足阈值的目标时，使用首次找到的位置；可通过限定范围消除歧义。
勾选“适配缩放”会搜索原尺寸及 50%～200% 的等比例缩放，以 5% 为间隔，优先常见比例。目标大小基本固定时，关闭此项可减少搜索开销。
此功能适合原图及缩放图，不处理旋转、透视变化或任意重新排版。遇到相似图像时提高相似度并缩小范围。

找到时执行条件内的步骤；找不到时进入“否则”，或在没有否则时跳到“结束条件”。“点击匹配中心”使用最近一层找到图像的条件结果，直接左键点击该矩形中心，不会再次截图。
可与循环、等待及其他条件嵌套；结构不能交叉，合计最多 16 层。重复检查可放入循环，未找到的分支中添加等待以控制频率。
识别在可取消的工作线程执行；F8、停止按钮或关闭窗口会取消后续点击，退出时等待线程结束并释放资源。

文字截图使用同一套图像匹配，不需要 OCR 模型。本版没有“输入文字识别”或读取任意字体文本的功能。

## 执行日志

点击底部“上次执行日志”，查看最近一次完成、停止或失败的任务，包括快速任务。再次打开程序仍可查看。
日志记录执行顺序、轮次、步骤、连点次数、自动抬起和失败原因；跳过的分支不会记为已执行动作。等待记录开始时间，提前停止可通过任务结束时间核对。
图像记录包括命中位置的相似度、设定阈值、中心坐标、缩放比例，以及截图和识别耗时。未找到时不计算全局最高相似度，日志显示“未找到”；汇总的“图像命中”是成功检查次数 / 已完成检查次数。取消中的识别单独记录，不算作未命中。
新任务运行期间可查看上一次日志，任务结束后自动更新。日志窗口不会阻止停止快捷键，可复制整份日志。
连续连点合并计数，最多保留最近 2000 条记录，保存大小不超过 2 MB；省略较早记录时会显示数量。汇总计数覆盖整次任务，日志仅在任务结束时保存，不逐次写盘。

## 图像验收示例

打开 `examples/image-matching/acceptance.html`，页面中的 36 个词汇都是超链接，点击会记录词汇。
导入同目录的 `click-all-words.json`，将网页保持可见（可在设置中开启启动后自动最小化），开始后按记录核对 36 个词汇是否各点击一次。
页面可切换显示比例；也可在图像条件中限定该页面的区域。验收脚本只模拟点击，运行前把目标页面放到前台。
各模板和词汇矩形记录在 `templates/` 和 `words.json`。

## 快捷键

默认 F6 启停任务、F8 立即停止、F7 启停录制。在“设置”页点击快捷键框，按一组按键即可保存。
Esc 清空并解除对应绑定；旁边的“重置”恢复该项默认快捷键。可以使用 Ctrl / Alt / Shift 等组合键。
占用冲突会提示并恢复原快捷键。F12 为 Windows 调试器保留键。
启动时如果快捷键被其他程序占用，原配置仍会保留，下次启动可以重新注册。
目标按键如果与已注册快捷键相同，会阻止运行，请先修改快捷键。
采集弹窗出现时，任务快捷键暂不触发动作，仍可采集 F6 / F7 / F8。

## FloatingBall

在 PowerShell 运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\register-floatingball.ps1
```

默认注册到 `D:\Small_App\MangaDownloadTools\FloatingBall`。其他位置可用 `-FloatingBall` 指定。
注册只更新 tools.json 的 liandianqi 项并备份原文件；FloatingBall 自动热重载。
“启”打开程序，“停”正常关闭程序并释放按键，“开”显示已打开的窗口。
运行任务仍使用本程序按钮或 F6，打开程序不会自动发送输入。
移动便携包后需重新注册。删除入口可运行 unregister-floatingball.ps1，不会删除其他工具。

## 关闭与资源

点窗口 × 会停止定时器、释放程序按住的键、移除输入采集钩子和快捷键、关闭本地控制接口并退出进程。
程序不驻留托盘、不安装系统服务、不添加开机启动。没有后台子进程。
空闲和无限长按状态没有执行轮询；录制/采集钩子仅在使用时存在。
配置与未保存的当前流程记忆保存在 `HKEY_CURRENT_USER\Software\DianXu\LianDianQi`，它是设置而不是常驻程序。
正常关闭的释放保证不适用于强制结束进程、断电或系统崩溃。

管理员权限的目标窗口需要连点器以同级权限运行；Windows 安全桌面和部分游戏可能拒绝模拟输入。
5 ms 为允许的最小间隔，实际精度取决于 Windows 调度和目标程序处理速度。

## 命令行

```text
LianDianQi.exe --show                 打开 / 显示窗口（单实例）
LianDianQi.exe --quit                 正常关闭运行中的实例
LianDianQi.exe --toggle               启停现有实例的任务
LianDianQi.exe --stop-task            停止任务，保留窗口
LianDianQi.exe --status               运行中返回 0，未运行返回 1
LianDianQi.exe --script script.json   打开并导入脚本
LianDianQi.exe --script script.json --run  打开后执行指定脚本
```

控制命令不启动新的常驻实例。重复打开只显示已有窗口；导入脚本参数仅在首次启动时生效。
`--quit` 收到成功响应后，主进程通常在随后几毫秒完成关闭。
